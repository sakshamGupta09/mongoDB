# Array operators

- Till now, we were updating documents. Now, we want up update array values.

## $push

- Add a value to the array.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/operator/update/push/)

```javascript
db.movies.updateOne(
   { title: "The Dark Knight" },
   { $push: { genres: "Classic" } }
)
```
### Add multiple values

```javascript
db.movies.updateOne(
   { title: "The Dark Knight" },
   { $push: { genres: { $each: [ "Modern Classic", "Award-Winning" ] } } }
)
```

```javascript
db.students.updateOne(
   { _id: 5 },
   {
     $push: {
       quizzes: {
          $each: [ { wk: 5, score: 8 }, { wk: 6, score: 7 }, { wk: 7, score: 6 } ],
          $sort: { score: -1 },
          $slice: 3
       }
     }
   }
)
```
- It sorts the entire array not just the new values.

## $pop

- Remove first or last element from array.
- 1 to remove last values. -1 for the first.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/operator/update/pop/)

```javacsript
db.students.updateOne( { _id: 1 }, { $pop: { scores: -1 } } )
```
```javascript
db.students.updateOne( { _id: 10 }, { $pop: { scores: 1 } } )
```

## $pull

- Remove elements based on a query.

```javascript
db.profiles.updateOne( { _id: 1 }, { $pull: { votes: { $gte: 6 } } } )
```
```javascript
db.survey.updateMany(
  { },
  { $pull: { results: { $elemMatch: { score: 8 , item: "B" } } } }
)
```
```javascript
db.stores.updateMany(
    { },
    { $pull: { fruits: { $in: [ "apples", "oranges" ] }, vegetables: "carrots" } }
)
```

## $addToSet

- Add a value to the array if it's not there already.

```javascript
db.pigments.updateOne(
   { _id: 1 },
   { $addToSet: { colors: "mauve" } }
)
```
```javascript
db.inventory.updateOne(
   { _id: 2 },
   { $addToSet: { tags: { $each: [ "camera", "electronics", "accessories" ] } } }
 )
```
