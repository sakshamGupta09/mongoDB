# Array Operators

- In previous module, we updated our array by adding or removing items. Now, we will update elements in an array.
- Question is which array elements to update. All elements, First matching, all matching.
- Syntax remains same. Operator --> field. What to specify for the field.


## Updating All

- Update all elements in array irrespective of the filter.
- $[] points to the element.

```javascript
db.collection.updateOne(
   { <query conditions> },
   { <update operator>: { "<array>.$[]" : value } }
)
```
```javascript
db.students.insertMany( [
   { "_id" : 1, "grades" : [ 85, 82, 80 ] },
   { "_id" : 2, "grades" : [ 88, 90, 92 ] },
   { "_id" : 3, "grades" : [ 85, 100, 90 ] }
] )
```
```javascript
db.students.updateMany(
   { },
   { $inc: { "grades.$[]": 10 } },
)
```
```javascript
{ "_id" : 1, "grades" : [ 95, 92, 90 ] }
{ "_id" : 2, "grades" : [ 98, 100, 102 ] }
{ "_id" : 3, "grades" : [ 95, 110, 100 ] }
```

## Update all documents

```javacsript
db.collection.updateOne(
   { <query selector> },
   { <update operator>: { "array.$[].field" : value } }
)
```

## Update First matching element

```javascript
db.collection.updateOne(
   { <array>: value ... },
   { <update operator>: { "<array>.$" : value } }
)
```
- We wrote a query on array using equality, $all or $elemMatch that matched 3 elements. But only update the first matching element.
- `field.$` refers to the first matching element of the array. It can be a primitive or an object on which we can mutate existing fields or add new ones.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/operator/update/positional/)

```javascript
db.students.insertMany( [
   { "_id" : 1, "grades" : [ 85, 80, 80 ] },
   { "_id" : 2, "grades" : [ 88, 90, 92 ] },
   { "_id" : 3, "grades" : [ 85, 100, 90 ] }
] )
```
```javascript
db.students.updateOne(
   { _id: 1, grades: 80 },
   { $set: { "grades.$" : 82 } }
)
```
```javascript
{ "_id" : 1, "grades" : [ 85, 82, 80 ] }
{ "_id" : 2, "grades" : [ 88, 90, 92 ] }
{ "_id" : 3, "grades" : [ 85, 100, 90 ] }
```

## Update first matching Documents in an Array

```javascript
{
  _id: 4,
  grades: [
     { grade: 80, mean: 75, std: 8 },
     { grade: 85, mean: 90, std: 5 },
     { grade: 85, mean: 85, std: 8 }
  ]
}
```
```javascript
db.students.updateOne(
   { _id: 4, "grades.grade": 85 },
   { $set: { "grades.$.std" : 6 } }
)
```
```javascript
{
   "_id" : 4,
   "grades" : [
      { "grade" : 80, "mean" : 75, "std" : 8 },
      { "grade" : 85, "mean" : 90, "std" : 6 },
      { "grade" : 85, "mean" : 85, "std" : 8 }
   ]
}
```

## Update all matching values

- Update all values of the array that match the query.
- Query can be totally different from array filters.

```javascript
db.users.updateMany(
  {},
  { $set: { "hobbies.$[el].goodFrequency": true } },
  { arrayFilters: [{ "el.frequency": { $gt: 3 } }] }
);

```
