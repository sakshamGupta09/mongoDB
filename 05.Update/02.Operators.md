# How to update

- We must pass an operator which tells MongoDB how we want to update this document.
- We can add new fields, update existing field, delete fields and rename keys. We have different operators for these operations.


## $set

- To add new fields to the document. If the field already exists, it's value is updated.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/operator/aggregation/set/#mongodb-pipeline-pipe.-set)

```javascript
{ $set: { rated: "UNRATED" } }
```
