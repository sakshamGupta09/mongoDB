# How to update

- We must pass an operator which tells MongoDB how we want to update this document.
- We can add new fields, update existing field, delete fields and rename keys. We have different operators for these operations.
- We can also add multiple operators.

```javascript
{ operator1: {}, operator2: {} }
```


## $set

- Add one or more new fields to the document. If the field already exists, it's value is replaced.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/operator/update/set/)

```javascript
db.movies.updateOne(
   { title: "The Dark Knight" },
   {
      $set: {
         label: "Award Winner",
         status: "classic"
      }
   }
)

```

## Updating values

- Update field value by using existing values.
- [$inc](https://www.mongodb.com/docs/v7.0/reference/operator/update/inc/)
- [$mul](https://www.mongodb.com/docs/v7.0/reference/operator/update/mul/)


```javascript
{ $mul: { <field1>: <Multiply with number1>, ... } }
```
```javacsript
{ $inc: { <field1>: <amount1>, <field2>: <amount2>, ... } }
```

## Min and Max

- Two values, existing and provided. Pick min or max out of these two and update original value.
- [$min](https://www.mongodb.com/docs/v7.0/reference/operator/update/min/)
- [$max](https://www.mongodb.com/docs/v7.0/reference/operator/update/max/)

```javascript
{ $min: { <field1>: <value1>, ... } }
```

```javascript
{ $max: { <field1>: <value1>, ... } }
```
