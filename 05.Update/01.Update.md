# Update

- Update one or more documents in a collection.
- Query is needed to filter which documents to update.
- MongoDB server replies with: I have acknowledged your request. The query matched these many documents and these many were actually modified.

## How to update

- We must pass an operator which tells MongoDB how we want to update this document.
- We can add new fields, update existing field, delete fields and rename keys. We have different operators for these operations.
- [$set operator](https://www.mongodb.com/docs/v7.0/reference/operator/aggregation/set/#mongodb-pipeline-pipe.-set)
- To add new fields to the document. If the field already exists, it is updated.


## UpdateOne(query, update, options): { matchedCount, modifiedCount, acknowledged}

- Update only one document.
- If multiple documents matches the query, Update the first one only.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.updateOne)


## UpdateMany(query, update, options): { matchedCount, modifiedCount, acknowledged}

- Update all the documents that matches the query.
- [updateMany](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.updateMany)


## replaceOne(query, replacement, options): { matchedCount, modifiedCount, acknowledged , upsertedId}

- Completely replace the matching document with this new one except `_id`.
- Client might be sending us full new document. In that case it's convinient to replace it completely.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.replaceOne)
