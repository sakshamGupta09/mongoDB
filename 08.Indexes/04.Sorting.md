# Sorting

- Sorting is an expensive operation.
- Indexes can speed up sorting since it already has ordered values.
- Sorting stage can be skipped altogether. Only FETCH stage and we get the result set.
- When adding indexes we need to consider sorting as well.


## Default Index

- MongoDB creates a default index ofr every collection on `_id` field.
- Because doing a collection scan to find just one record is inefficient.
