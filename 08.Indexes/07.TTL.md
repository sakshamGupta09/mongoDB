# Time To Live Index

- Each document in this collection should have an expiry date. Documents are automatically deleted after expiry date. Example: email invitations or OTPs.
- Only works for datetime fields.

## Session / Login expiration

- Store user sessions that should automatically expire.

```javascript
db.sessions.createIndex(
  { createdAt: 1 },
  { expireAfterSeconds: 86400 }
)
```

## Temporary OTP / Verification codes

- Email verification, password reset, login OTPs.

```javascript
db.otps.createIndex(
  { expiresAt: 1 },
  { expireAfterSeconds: 0 }
)
```
