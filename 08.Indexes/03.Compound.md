# Compound index

- Our query uses multiple fields(name and age). Having separate indexes on `name` and `age` will not help to retrieve records efficiently.
- We create a compound index. Each node will have name, age and pointer ordered by name first and then age. Query can check both name and age from index only.
- Order is very important because the index is sorted first by the first field, then by the second.
- Compound index can also be leveraged if we query by only `name` as we have sorted names in our index.

```javascript
db.collection.createIndex({ name: 1, age: -1 })
```

## Explain

```javascript
db.collection.explain(queryPlanner || executionStats || allPlansExecution).find()
```

- We created indexes. But how do we know if they are working as expected.
- We use explain method that gives us different plans MongoDB considered to evaluate this query and the winning plan.
