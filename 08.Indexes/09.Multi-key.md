# Multi Key Indexes

- An index contains ordered values of a column. What if that column is an array?
- All the values of array are stored in index separately along with a pointer to original document.
- The size of index will be greater than number of documents.
- Writes will be relatively expensive.
- Compound indexes are possible using one multi key index. Multiple are not allowed.

```javascript
db.collection.createIndex({ arrayOfPrmitives: 1 ])
```

```javascript
db.collection.createIndex({ arrayOfObjects.objectKey: 1 ])
```
