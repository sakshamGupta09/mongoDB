# Unique index

- This column should have unique values only like email or phone number.
- If an insert/update operation tries to insert a existing value, it will fail.
- `_id` has a unique index by default. That's why we cannot add duplicate ids.

```javascript
db.collection.createIndex( { email: 1 }, { unique: true } )
```
- If we add unique index to an existing collection, it will only work if collection has unique elements.
