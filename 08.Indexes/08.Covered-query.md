# Covered Query

- A single field index will contain a single value. But we might need additional fields in the result set, for which we do a `FETCH` stage.
- But, if we don't need all fields in the result set and only the values that are already in the index, in that case we don't need a `FETCH` stage. Index can return the result set on it's own.
- This is called a covered query and will be super fast.
