# Multi Key Indexes

- An index contains ordered values of a column.
- In case of an array, all the values of array are stored in index separately along with a pointer to original document.
- The size of index will be greater than number of documents.
- Writes will be relatively expensive.
- We can create compound indexes as well using one multi key index.

```javascript
db.collection.createIndex({ arrayOfPrmitives: 1 ])
```

```javascript
db.collection.createIndex({ arrayOfObjects.objectKey: 1 ])
```
