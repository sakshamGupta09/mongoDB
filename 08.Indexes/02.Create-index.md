# Create Index

```javascript
db.collection.createIndex({ field: <1, -1> })
```
- We can create indexes on embedded fields as well.

## Compound index

- If Queries often filter using multiple fields like `name` and `age`. In this case having two separate indexes on `name` and `age` does not help much.
- Node now has 3 values, First ordered by `name`, then ordered by `age`. If we have a query like find all people with name John and age 30, we can return results easily.
- Order is very important because the index is sorted first by the first field, then by the second.
- Left to right, we can query using the compound index as well.

```javascript
db.collection.createIndex({ name: 1, age: -1 })
```

## Explain

```javascript
db.collection.explain(queryPlanner || executionStats || allPlansExecution).find()
```

- We created indexes. But how do we know if they are working as expected.
- We use explain method that gives us different plans MongoDB considered to evaluate this query and the winning plan.

## List indexes

```javascript
db.collection.getIndexes()
```

## Drop Index

```javascript
db.collection.dropIndex({field: <1,-1>})
```
- We can also drop an index by name.

```javascript
db.collection.dropIndex(name)
```
