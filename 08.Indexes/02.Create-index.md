# Create Index

```javascript
db.collection.createIndex({ field: <1, -1> })
```
- We can create indexes on embedded fields as well.

## Compound indexe

- Built on multiple fields together.
- Your queries often filter using multiple fields.
- Order is very important because the index is sorted first by the first field, then by the second.


## Explain

```javascript
db.collection.explain().find()
```

- We created indexes. But how do we know if they are working as expected.
- We use explain method that gives us different plans MongoDB considered to evaluate this query and the winning plan.
