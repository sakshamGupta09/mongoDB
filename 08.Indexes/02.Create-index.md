# Create Index

```javascript
db.collection.createIndex({ field: <1, -1> })
```
- This locks the collection and we cannot access (Read or write) it as it is creating a new data structure.
- If we have like 10 million documents, creating index will take time and our collection will be locked till then.

```javascript
db.collection.createIndex({ field: <1, -1> }, { background: true })
```
- Index is created in a way that collection won't be locked.

## List indexes

```javascript
db.collection.getIndexes()
```


## Drop Index

```javascript
db.collection.dropIndex({field: <1,-1>})
```
- We can also drop an index by name.

```javascript
db.collection.dropIndex(name)
```
