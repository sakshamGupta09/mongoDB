# Create Index

```javascript
db.collection.createIndex({ field: <1, -1> })
```
- This locks the collection and we cannot edit it as it is creating a new data structure.

```javascript
```

## List indexes

```javascript
db.collection.getIndexes()
```


## Drop Index

```javascript
db.collection.dropIndex({field: <1,-1>})
```
- We can also drop an index by name.

```javascript
db.collection.dropIndex(name)
```
