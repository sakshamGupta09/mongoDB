# Covered Query

- Our indexes work in two stages.
- `IXSCAN` where we search the ordered index for particular values.
- `FETCH` For the matching values we go via pointer to original collection to get all fields.
- We do not want to read all fields. Only the fields which are lready there in the index. In this case we don't need the FETCH stage at all and this will be sper fast.
