# Text Index

- We have a field (product description) with large text and we want to search in that text.
- All the stop words are removed. Only keywords are stored in a multi key index.
- There can be only one text index in a collection.
- Casing is not important. Everything is stored as lowercase.

```javascript
db.collection.createIndex({ description: "text" })
```


## $text

- To query a field with text index, we use a special operator.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/text/#mongodb-query-op.-text)

```javascript
db.movies.find(
   { $text: { $search: "baseball" }, runtime: { $gt: 1000 } },
)
```

- Space separated values are treated like OR.

```javascript
db.movies.find(
   { $text: { $search: "baseball colorado" },
     runtime: { $gt: 1000 } },
   { _id: 0, title: 1, year: 1, runtime: 1, fullplot: 1 }
)
```

- Escape the quotes to match an exact multi-word string.

```javascript
db.movies.find(
   { $text: { $search: "\"ken burns\"" },
     runtime: { $gt: 1000 } },
)
```

## Scores

- When we search a keyword in text index, MongoDB assigns a score to every match.

```javascript
db.articles.aggregate(
   [
     { $match: { $text: { $search: "cake tea" } } },
     { $sort: { score: { $meta: "textScore" } } },
     { $project: { title: 1, _id: 0 } }
   ]
)
```
