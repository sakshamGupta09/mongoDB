# Delete

- Delete one or multiple documents.
- Query is needed to select which documents to delete. If empty query is provided, all documents will be deleted.
- MongoDB server replies: I have acknowledged your request and deleted these many documents.

## DeleteOne(filter, options): { acknowledged, deletedCount }

- Delete only one document.
- If there are multiple documents matching the query, delete the first matching document.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.deleteOne)

## deleteMany(filter, options): { acknowledged, deletedCount }

- Delete all the documents that are matching query.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.deleteMany)


## Delete collection

```javascript
db.collection.drop()
```
Returns a boolean indicating if collection was deleted or not.

## Delete database

```javascript
db.dropDatabase()
```
