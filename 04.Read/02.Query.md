# Query

- Query is an object with fields and values.
- Field refers to the field in the document and it's value is compared with value in the query object.

```javascript
db.movies.findOne({name: "Under the Dome"})
```
- This is an equality match. Go to all the documents and return the ones where name field has a value of "Under the Dome".

```javascript
db.movies.findOne({name: "Under the Dome", id: 1})
```
- If we write multiple key value pairs in our query, then it becomes an AND.
