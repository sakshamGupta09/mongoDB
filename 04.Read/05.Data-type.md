# Data type operators

| Operator | Description |
| --- | --- |
| `$exists` | Matches documents that have the specified field. |
| `$type` | Matches documents if a field is of the specified type. |


### $exists

- So, `$exists` is used to get documents where a particular field exists or not.
- Values are not checked only existence of field is important.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/exists/)

```javascript
db.movies.find( { rated: { $exists: false } })
```

- First check if the field exists and then another condition

```javascript
db.movies.find( { ratings: { $exists: true, $gte: 9 } })
```

```javascript
{totalAge: {$exists: true, $ne: null}}
```

### $type

- Value of this field should be of given type.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/type/)
- [BSON Types](https://www.mongodb.com/docs/manual/reference/bson-types/#std-label-bson-types)

```javascript
{ field: { $type: <BSON type> } }
```
```javascript
{ field: { $type: [ <BSON type1> , <BSON type2>, ... ] } }
```
