# Projection

- Documents in a collection, might contain 100s of fields. Client only needs 10 of them.
- Sending All 100 fields means more data needs to be transferred over the wire causing more bandwidth, time and consume more memory resources.
- With projection we say to our DB server, that I want documents from this collection and each document should have only these fields.
- By default, `_id` will always be part of the response even if we do not include it in projection. We explicitly have to set it to 0 to remove it from response.
