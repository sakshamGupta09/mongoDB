# Read

- Read one or more documents from a collection.


## findOne(query, projection, options) : Document | null

- Read only one document from a collection.
- If there are multiple matching documents, return me the first one.
- If none of the documents matches the query, return null.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.findOne)

## find(query, projection, options) : Cursor

- I want to read all the matching documents.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.find)

## Query

- I do not want to read all the documents but a subset of them. We filter documents in a collection using query.
- We write a field name and then compare it with a value.

## Cursor

- `find` method can result in potentially very large result sets. This is bad because -
- 10 million documents need to travel over the wire from DB server to the application which will be slow and consume more bandwidth. Application memory can crash while storing such huge volume of data. Presenting 10 million documents makes no sense to the user from usability perspective as well.
- So, we get back a cursor not documents.
- MongoDB server sends us the results in batches. We can iterate on cursor to fetch next batches.
- We have methods available on cursor to read documents from it.
