# Read

- I want to read one or more documents from a collection.


## findOne(query, projection, options) : Document | null

- I want to read only one document from a collection.
- If there are multiple matching documents, return me the first one.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.findOne)

## find(query, projection, options) : Cursor

- I want to read all the matching documents.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.find)
