# Array Operators

- We have a field with array value and we need to decide if it should be in result set or not by querying the array.
- [Docs](https://www.mongodb.com/docs/manual/reference/mql/query-predicates/arrays/)


| Name | Description |
| --- | --- |
| `$all` | Matches arrays that contain all elements specified in the query. |
| `$elemMatch` | Selects documents if at least one element in the array field matches all the specified `$elemMatch` conditions. |
| `$size` | Selects documents if the array field contains the specified number of elements. |


## $size

- Size of array must be equal to k.
- We can check for exact size only, not greater than or less than.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/size/)

```javascript
db.collection.find( { field: { $size: 2 } } );
```

## $all

```javascript
{ <field>: { $all: [ <value1> , <value2> ... ] } }
```
```javascript
{ tags: { $all: [ "ssl" , "security" ] } }
```

- All the values should be there in the array in any order. It may have additional elements.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/all/#mongodb-query-op.-all)


## $elemMatch

- There should be at least one element in array that satisfies all the conditions in the query.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/elemmatch/)

```javascript
{ <field>: { $elemMatch: { <condition 1>, <condition 2>, ... } } }
```

```javascript
db.scores.find(
   { results: { $elemMatch: { $gte: 80, $lt: 85 } } }
)
```
```javascript
db.survey.find(
   { results: { $elemMatch: { product: "xyz", score: { $gte: 8 } } } }
)

```
