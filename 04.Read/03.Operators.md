# Operators

- I don't want equality comparison.
- In this case, we still write a query object with a key and a value. But value this time will be another object using some operator.

## Comparison

- Compare the document field's value with a provided value.

```javascript
{ field: { operator: value } }
```

| Operator | Description |
| --- | --- |
| `$eq` | Matches values equal to a specified value. |
| `$gt` | Matches values greater than a specified value. |
| `$gte` | Matches values greater than or equal to a specified value. |
| `$in` | Matches any values specified in an array. |
| `$lt` | Matches values less than a specified value. |
| `$lte` | Matches values less than or equal to a specified value. |
| `$ne` | Matches all values not equal to a specified value. |
| `$nin` | Matches if the value is not equal to any of a given list of values. |
