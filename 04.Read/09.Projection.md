# Projection

- Documents in a collection, might contain 100s of fields. Client only needs 10 of them.
- Sending all 100 fields means more data needs to be transferred over the wire causing more bandwidth, time and consume more memory resources.
- I want these fields only in my result set.
- By default, `_id` will always be part of the result set even if we do not include it in projection. We explicitly have to set it to 0 to remove it from response.

```javascript
const cursor = db
  .collection('inventory')
  .find({
    status: 'A'
  })
  .project({ item: 1, status: 1 });

```

```javascript
db.collection.find(query, projection)
```
