# Evaluation Operartors

## $regex

- To do pattern matching. Like autocompletion. Typing "18 pro" should match "Apple iphone 18 pro max"
- Not very performant.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/regex/)


| Goal | Pattern |
| --- | --- |
| starts with Bro | `/^Bro/` |
| ends with Bar | `/Bar$/` |
| contains Bar anywhere | `/Bar/` |
| case-insensitive contains | `/bar/i` or `{ $regex: "bar", $options: "i" }` |
| starts with any of a set | `/^[BCD]/` |

## $expr

- To compare two field's values within a document.
- We can use comparison operators like $eq, $lt, $lte, $gt, and $gte.
- Notice the use of $sign to read values.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/expr/)

```javascript
{ $expr: { $gt: [ "$tomatoes.viewer.rating", "$tomatoes.critic.rating" ] } },
```

```javascript
{ $expr: { $gt: [ Value 1, Value 2 ] } },
```

## $cond

- Expression compares two values.
- We want to conditionally provide one value.

```javascript
db.movies.find(
   {
      $expr: {
         $gt: [
            {
               $cond: {
                  if: { $gte: ["$imdb.votes", 1000] },
                  then: { $multiply: ["$imdb.rating", 1.0] },
                  else: { $multiply: ["$imdb.rating", 0.5] }
               }
            },
            9
         ]
      }
   }
```
