# Embedded documents and Arrays

- A Document contains key value pairs.
- The value can be another document or an array of items where items can be primitive or document.
- While defining our query, we are not limited to just top level fields.


## Array of primitives

- Check if this value is in the list or not. There may be other values and that is okay.
- Go over all the elements and see if any of the element is having this value. If yes, that document is selected.

## Array of documents

- Query the array field by using the dot notation to go to the document field we want to query for.


## Nested documents

- We can just write the path of nested field from top level using dot notation.
- Once there, we can compare the value using operators we learnt about.

```javascript
{"rating.average": {$gte: 8}}
```
