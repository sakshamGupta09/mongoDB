# Operators

- I don't want equality comparison. I want to compare document value with another value.
- In this case, we still write a query object with a key and a value. But value this time will be another object using some operator.

```javascript
{ field: { operator: value } }
```
- Inside the object we can use multiple operators as key value pairs.

## Comparison

- Compare the document field's value with a provided value.
- [Docs](https://www.mongodb.com/docs/manual/reference/mql/query-predicates/comparison/)


| Operator | Description |
| --- | --- |
| `$eq` | Matches values equal to a specified value. |
| `$gt` | Matches values greater than a specified value. |
| `$gte` | Matches values greater than or equal to a specified value. |
| `$in` | Matches any values specified in an array. |
| `$lt` | Matches values less than a specified value. |
| `$lte` | Matches values less than or equal to a specified value. |
| `$ne` | Matches all values not equal to a specified value. |
| `$nin` | Matches if the value is not equal to any of a given list of values. |


## Logical

- Chain multiple queries using OR, AND.

### $or

- Either rating is less than 3 or greater than 9.
- Either one of the queries should be true.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/or/)

```javascript
{ $or: [ { query1 }, { query2 } ] }
```

```javascript
{$or: [{"rating.average": {$lte: 5}}, {"rating.average": {$gte: 9.3}}]}
```

## $and

- By default if we write multiple different fields in a query, it does an AND operation.
- But if want to add multiple AND conditions on the same field, this doesn't work. Because in JSON, adding existing key updates the value.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/query/and/)

```javascript
{language: "English", language: "Japanese"}
```
- This will only return Japanese movies.

```javascript
{$and: [{"rating.average": {$gt: 9}}, {genres: "Drama"}]}
```
