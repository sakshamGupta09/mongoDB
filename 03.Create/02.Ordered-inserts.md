# Ordered inserts

- Insert documents one by one, and stop when one fails
- If there is an error in inserting 5th document, the operation will stop and it will not insert next documents. But the first 4 documents before error will be inserted.
- The next documents might have been successfully inserted had the operation not stopped.


```javascript
db.hobbies.insertMany([
  { _id: "Sports", name: "Sports" },
  { _id: "Cooking", name: "Cooking" },
  { _id: "Reading", name: "Reading" },
]);


db.hobbies.insertMany([
  { _id: "Hiking", name: "Hiking" },
  { _id: "Cooking", name: "Cooking" },
  { _id: "Painting", name: "Painting" },
]);

// Hiking is inserted. Also, Painting is not even though it would have succeeded.
```
