# Write Concern

- We send a write request to DB server. DB server completes the request and send us the confirmation.
- We want to control when should MongoDB server send us the confirmation.

## Problem

```text
             ┌── Primary
Application ─┤
             ├── Secondary 1
             └── Secondary 2
```
- MongoDB has replica sets. The primary receives the write and replicates it to the secondaries.

```javascript
db.users.insertOne({ name: "Saksham" })
```

- When should MongoDB send the success response back to my application?


## The three important levels


```javascript
{ w: 1 }
```

- Tell me success once the primary has stored the write.
- The secondaries don't have to acknowledge before your application gets success.
- If the primary crashes immediately afterward before replicating the write, that write could potentially be lost during a failure scenario.
