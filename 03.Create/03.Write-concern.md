# Write Concern

- We send a write request to DB server. DB server completes the request and send us the confirmation.
- We want to control when should MongoDB server send us the confirmation.

## Problem

```javascript
db.users.insertOne({ name: "Saksham" })
```

```text
             ┌── Primary
Application ─┤
             ├── Secondary 1
             └── Secondary 2
```
- MongoDB has replica sets. The primary receives the write and replicates it to the secondaries.
- When should MongoDB send the success response back to my application?
