# Create

- Insert one or more documents in a collection.
- MongoDB generates a unique id for every document inserted and gives that is to us as `_id`.
- MongoDB server says, I have received your request (acknowledged) and here is the `_id` of the document/s inserted.


## insertOne(document, options) : { acknowledged, insertedId }

- Insert only one document in a collection.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.insertOne)


## insertMany(Array of documents, options): { aacknowledged, insertedIds }

- Insert multiple documents in a collection.
- We pass an array of documents.
- [docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.insertMany)
