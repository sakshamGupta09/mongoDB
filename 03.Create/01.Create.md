# Create

- Insert one or more documents in a collection.
- MongoDB generates a unique `_id` for every document insterted.


## insertOne(document, options) : { acknowledged, insertedId }

- I want to insert only one document in a collection.
- MongoDB assigns a unique _id value to all the documents added automatically.
- [Docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.insertOne)


## insertMany(documents, options): { aacknowledged, insertedIds }

- I want to insert multiple documents in a collection.
- [docs](https://www.mongodb.com/docs/v7.0/reference/method/db.collection.insertMany)
