# What is Aggregation

- MongoDB suggests storing data in the format that we are gonna read later.
- But sometimes, we need to read data and do complex transformations on it like grouping, joining etc.
- We build a pipeline of steps(stages) to slowly transform our data step by step.
- Each stage takes some input documents, processes them and gives output to the next stage. In the end we get the desired output.

```javascript
db.collection.aggregate([{stageName: { configure stage }])
```
