# Bucket

- Based on values of this field, create categories.
- This is different than grouping because we are considering range of values as one category not a single value.
- Then for each category, what result do I want to see.
- Each bucket will have results for lower bound inclusive and upper bound exclusive.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/bucket/)

```javascript
{
  $bucket: {
      groupBy: <expression>,
      boundaries: [ <lowerbound1>, <lowerbound2>, ... ],
      default: <literal>,
      output: {
         <output1>: { <$accumulator expression> },
         ...
         <outputN>: { <$accumulator expression> }
      }
   }
}
```

## $bucketAuto

- Bucket boundaries are automatically determined in an attempt to evenly distribute the documents into the specified number of buckets.

```javascript
{
  $bucketAuto: {
      groupBy: <expression>,
      buckets: <number>,
      output: {
         <output1>: { <$accumulator expression> },
         ...
      }
      granularity: <string>
  }
}
```
