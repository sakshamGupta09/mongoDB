# What is Aggregation

- Sometimes reading data in the format it is stored is not enough. We need to do more complex transformations to our data.
- We build a pipeline of steps(stages) to slowly transform our data step by step.
- Each stage takes some input documents, processes them and gives output to the next stage. In the end we get a desired output.

```javascript
db.collection.aggregate([stages])
```

## Match

- Match stage is same to query we pass to find methods.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/match/)

```javascript
db.movies.aggregate(
    [ { $match : { rated : "TV-PG", runtime : { $gt: 1000 } } } ]
)
```

## Sort

- Same syntax like we have learned earlier
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/sort/)

```javacsript
db.restaurants.aggregate(
   [
     { $sort : { borough : 1 } }
   ]
)
```
