# Type conversions

- Convert a value form one type to another.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/convert/)

## $convert

```javascript
{
   $convert:
      {
         input: <expression>,
         to: <type expression> || {
            type: <type expression>,
            subtype: <int>
         },
         base: <expression>,       // new in 8.3
         format: <string>,
         onError: <expression>,
         onNull: <expression>
      }
}
```

```javascript
{
  $convert: {
    input: "$location.coordinates.latitude",
    to: "double",
    onError: 0,
    onNull: 0
  }
}
```
```javascript
db.persons.aggregate([
  {
    $project: {
      birthDate: {
        $convert: {
          input: "$dob.date",
          to: "date",
          onError: null,
          onNull: null,
        },
      },
    },
  },
]);

```

## Shortcuts

- Shortcuts can be used to convert to a specific type.  Do not offer support for `onError` and `onNull`.
- $toArray, $toBool, $toDate, $toDecimal, $toDouble, $toInt, $toLong, $toObject, $toObjectId, $toString, $toUUID.
