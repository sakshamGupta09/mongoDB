# Type conversions

- Convert a value form one type to another.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/convert/)

## $convert

```javascript
{
   $convert:
      {
         input: <>,
         to: <type expression> || {
            type: <type expression>,
            subtype: <int>
         },
         base: <expression>,  
         format: <string>,
         onError: <expression>,
         onNull: <expression>
      }
}
```
