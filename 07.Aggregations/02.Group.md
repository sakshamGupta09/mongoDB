# Group

- Split our collection into multiple collections based on one or more fields.
- Perform some aggregation so that each group returns exactly one document.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/group/)

```javascript
{
 $group:
   {
     _id: <expression>, // Group key
     <field1>: { <accumulator1> : <expression1> },
     ...
   }
 }
```
```javascript
db.persons.aggregate([
  { $match: { gender: "female" } },
  {
    $group: { _id: { state: "$location.state" }, totalPersons: { $count: {} } },
  },
]);

```

## Accumulators

| Accumulator | Description | Example |
| --- | --- | --- |
| **Count** | Counts the number of documents in a group | `total += price` |
| **Count Accumulator** | Increments a value by a fixed amount (usually 1) to track occurrences or loop steps. | `count += 1` |
| **String Concatenator** | Appends new characters or text fragments onto an existing text variable. | `message += " " + word` |
| **List/Collection Builder** | Appends individual items or elements into an array, vector, or list. | `items.append(new_item)` |
| **Product Accumulator** | Multiplies a running total by each incoming value (commonly used in factorials). | `factorial *= i` |
| **Flag/State Accumulator** | Combines boolean conditions (often using `AND` or `OR`) to track an overall state. | `is_valid = is_valid && check()` |
