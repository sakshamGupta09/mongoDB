# Stages


## Match

- Match stage is same to query we pass to find methods.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/match/)

```javascript
db.movies.aggregate(
    [ { $match : { rated : "TV-PG", runtime : { $gt: 1000 } } } ]
)
```

## Sort

- Same syntax like we have learned earlier.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/sort/)

```javascript
db.restaurants.aggregate(
   [
     { $sort : { borough : 1 } }
   ]
)
```

## Projection

```javascript
{ $project: { contact: 1, "contact.address.country": 1 } }
```
- Most of the features are same except that we can create new fields on the fly and assign them values using existing field values.

```javascript
db.persons.aggregate([
  {
    $project: {
      fullName: {
        $concat: ["$name.title", " ", "$name.first", " ", "$name.last"],
      },
    },
  },
]);
```

```javascript
db.persons.aggregate([
  {
    $project: {
      fullName: {
        $concat: [
          { $toUpper: { $substrCP: ["$name.title", 0, 1] } },
          {
            $toLower: {
              $substrCP: [
                "$name.title",
                1,
                { $subtract: [{ $strLenCP: "$name.title" }, 1] },
              ],
            },
          },
        ],
      },
    },
  },
]);
```
