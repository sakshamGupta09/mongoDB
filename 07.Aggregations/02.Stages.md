# Stages


## Match

- Match stage is same to query we pass to find methods.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/match/)

```javascript
db.movies.aggregate(
    [ { $match : { rated : "TV-PG", runtime : { $gt: 1000 } } } ]
)
```

## Sort

- Same syntax like we have learned earlier.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/sort/)

```javascript
db.restaurants.aggregate(
   [
     { $sort : { borough : 1 } }
   ]
)
```

## Projection

```javascript
{ $project: { contact: 1, "contact.address.country": 1 } }
```
- Till now we used projection to indicate which fields we want in the result set.
- We can create new fields on the fly and assign them values using existing field values.
- We can supply 1 or 0 to indicate whether field should be included in result set or not.
- We can also supply a completely new value.
- `$` sign tells MongoDB that this is not a hardcoded string but value of a field in document.

```javascript
db.persons.aggregate([
  {
    $project: {
      fullName: {
        $concat: ["$name.title", " ", "$name.first", " ", "$name.last"],
      },
    },
  },
]);
```

```javascript
db.persons.aggregate([
  {
    $project: {
      fullName: {
        $concat: [
          { $toUpper: { $substrCP: ["$name.title", 0, 1] } },
          {
            $toLower: {
              $substrCP: [
                "$name.title",
                1,
                { $subtract: [{ $strLenCP: "$name.title" }, 1] },
              ],
            },
          },
        ],
      },
    },
  },
]);
```

```javascript
db.persons.aggregate([
  {
    $project: {
      location: {
        type: "Point",
        coordinates: [
          "$location.coordinates.latitude",
          "$location.coordinates.longitude",
        ],
      },
    },
  },
]);

```
