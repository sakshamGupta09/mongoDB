# Group

- Split our collection into multiple collections based on one or more fields.
- Perform some aggregation so that each group returns exactly one document.
- That document will have two fields one will be `_id` and second a custom value.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/group/)

```javascript
{
 $group:
   {
     _id: <expression>, // Group key
     <field1>: { <accumulator1> : <expression1> },
     ...
   }
 }
```
```javascript
db.persons.aggregate([
  { $match: { gender: "female" } },
  {
    $group: { _id: { state: "$location.state" }, totalPersons: { $count: {} } },
  },
]);

```

## Group by year

- We can use some operators to extract value from fields and then group by that values.
- Example: Group by year when we have ISODate.

```javascript
db.persons.aggregate([
  {
    $group: {
      _id: { birthYear: { $year: "$birthDate" } },
      count: { $count: {} },
    },
  },
]);

```
