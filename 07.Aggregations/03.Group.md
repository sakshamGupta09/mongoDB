# Group

- Split our collection into multiple collections based on one or more fields.
- Perform some aggregation so that each group returns exactly one document.
- That document will have two fields one will be `_id` and second a custom value.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/group/)

```javascript
{
 $group:
   {
     _id: <expression>, // Group key
     <field1>: { <accumulator1> : <expression1> },
     ...
   }
 }
```
```javascript
db.persons.aggregate([
  { $match: { gender: "female" } },
  {
    $group: { _id: { state: "$location.state" }, totalPersons: { $count: {} } },
  },
]);

```

## Group by year

- It's not mandatory that we always group by exact field value. We can group by a derived value as well.
- Example: Group by year when we have ISODate.

```javascript
db.persons.aggregate([
  {
    $group: {
      _id: { birthYear: { $year: "$birthDate" } },
      count: { $count: {} },
    },
  },
]);

```

## $push

- We merge the group documents into one using an accumulator.
- We want to create a new array and keep adding values to it for each document.
- If the value is already an array we get an array of arrays.

```javascript
db.sales.aggregate(
   [
   { $sort: { date: 1, item: 1 } },
   {
       $group:
         {
           _id: { day: { $dayOfYear: "$date"}, year: { $year: "$date" } },
           itemsSold: { $push:  { item: "$item", quantity: "$quantity" } }
         }
     }
   ]
)
```
