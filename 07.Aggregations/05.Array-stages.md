# Array stages

## $unwind

- Takes one document and spits out multiple based on array size.
- For each array element, output a new document with that element value.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/unwind/)

```javascript
db.inventory.aggregate( [ { $unwind : "$sizes" } ] )
```
```javascript
db.exams.aggregate([
  { $unwind: "$hobbies" },
  { $group: { _id: { age: "$age" }, hobbies: { $push: "$hobbies" } } },
]);
```

## Projection with arrays

- We can add new fields while projection. The new field's value can be derived using operators.
- We can use negative index values as well.

```javascript
db.exams.aggregate([
  { $project: { examScore: { $slice: ["$examScores", 1] } } },
]);
```

```javascript
db.exams.aggregate([
  { $project: { examScore: { $slice: ["$examScores", -1] } } },
]);
```
```javascript
db.exams.aggregate([
  { $project: { examScore: { $slice: ["$examScores", 2, 1] } } },
]);
```
