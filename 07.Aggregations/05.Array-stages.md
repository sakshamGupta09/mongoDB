# Array stages

## $unwind

- Takes one document and spits out multiple based on array size.
- For each array element, output a new document with that element value.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/unwind/)

```javascript
db.inventory.aggregate( [ { $unwind : "$sizes" } ] )
```
```javascript
db.exams.aggregate([
  { $unwind: "$hobbies" },
  { $group: { _id: { age: "$age" }, hobbies: { $push: "$hobbies" } } },
]);
```

## Projection with arrays

- We can add new fields while projection. The new field's value can be derived using operators.
- We can use negative index values as well.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/slice/)

```javascript
db.exams.aggregate([
  { $project: { examScore: { $slice: ["$examScores", 1] } } },
]);
```

```javascript
db.exams.aggregate([
  { $project: { examScore: { $slice: ["$examScores", -1] } } },
]);
```
```javascript
db.exams.aggregate([
  { $project: { examScore: { $slice: ["$examScores", 2, 1] } } },
]);
```

## Length of an array

-[Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/size/)

```javascript
db.exams.aggregate([{ $project: { numExams: { $size: "$exams" } } }]);
```

## $filter

- Add a new field whose value is derived by filtering some values from input array.
- [Docs](https://www.mongodb.com/docs/manual/reference/operator/aggregation/filter/)

```javascript
db.sales.insertMany( [
   {
      _id: 0,
      items: [
         { item_id: 43, quantity: 2, price: 10, name: "pen" },
         { item_id: 2, quantity: 1, price: 240, name: "briefcase" }
      ]
   },
   {
      _id: 1,
      items: [
         { item_id: 23, quantity: 3, price: 110, name: "notebook" },
         { item_id: 103, quantity: 4, price: 5, name: "pen" },
         { item_id: 38, quantity: 1, price: 300, name: "printer" }
      ]
   },
   {
      _id: 2,
      items: [
         { item_id: 4, quantity: 1, price: 23, name: "paper" }
      ]
   }
] )
```
```javascript
db.sales.aggregate( [
   {
      $project: {
         items: {
            $filter: {
               input: "$items",
               as: "item",
               cond: { $gte: [ "$$item.price", 100 ] }
            }
         }
      }
   }
] )
```
