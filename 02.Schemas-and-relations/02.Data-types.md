# Data Types

- What type of values can be stored in a field.
- Incoming values will be validated and accepted only if they are of the right type.
- [List of data types](https://www.mongodb.com/docs/manual/reference/bson-types/)


## Numeric

- Mumbers can be classified as integers and decimals.
- To store integers we have `int` which is 32-bit integer and long which is 64-bit integer. If we store values outside the range, we will get a different number.

| | `Double` | `Decimal128` |
|---|---|---|
| BSON type | Double | Decimal |
| Size | 8 bytes | 16 bytes |
| Precision | ~15–17 significant digits | 34 significant digits |
| Representation | Binary floating point | Decimal floating point |
| Exact decimal values | ❌ Not always | ✅ Yes |
| Performance | Faster | Slightly slower |
| Best for | Scientific calculations, measurements | Money, financial data |

With Double: 

```javacsript
0.1 + 0.2
// 0.30000000000000004
```
This happens because numbers like 0.1 cannot be represented exactly in binary floating point.


With Decimal128:

```javascript
Decimal128("0.1") + Decimal128("0.2")
// 0.3
```
