# Relations

- Documents in different collections can be related to each other. How do we map those relations?
- We have two ways of storing relations - Embedded documents and Reference.

## One to One Relations

- User and Passport. One User has exactly one Passport. One Passport belongs to exactly one User.

## Embedding

- Embed when the data belongs together and is usually accessed together. In this case we have a screen where we show users and their passport details.
- Child data doesn't change independently. Passport only exists because a user exists.
- The embedded data is small and bounded.
