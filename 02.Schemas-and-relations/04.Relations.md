# Relations

- Documents in different collections can be related to each other. How do we map those relations?
- We have two ways of storing relations - Embedded documents and Reference.

## Embedding

- Embed when the data belongs together and is usually accessed together.
- If an address is only meaningful as part of the user, embedding is natural.
- Child data doesn't change independently.
- The embedded data is small and bounded and unique.


## Reference

- The related data has its own lifecycle.
- Many documents share the same entity.
- You frequently access the related data independently.
- The embedded document could make the parent document too large.

| Question | Prefer |
|---|---|
| Usually read together? | **Embed** |
| Child belongs exclusively to parent? | **Embed** |
| Small and bounded? | **Embed** |
| Child has independent lifecycle? | **Reference** |
| Shared by many documents? | **Reference** |
| Potentially unbounded growth? | **Reference** |
| Frequently queried independently? | **Reference** |
