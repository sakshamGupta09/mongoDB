# Guidelines

- What kind of data will this feature generate. Based on this we can create some entities and define attributes.
- How are entities related and how to map the relation.
- How does consumer use this data. Store it in a way that it's easier to retrieve later. Revisit step one and two to validate of it is indeed easier for consumer or not.
- Think of queries, filters and indexes.
- Is it a read heavy or a write heavy system.


## Data Types

- What type of values can be stored in a field.
- Incoming values will be validated and accepted only if they are of the right type.
