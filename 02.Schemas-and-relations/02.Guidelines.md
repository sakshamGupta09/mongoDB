# Guidelines

- What kind of data will this feature generate. Based on this we can create some entities and define attributes.
- How does consumer use this data. Store it in a way that it's easier to retrieve later.
- Think of queries, filters and indexes.
- Is it a read heavy or a write heavy system. For write heavy, we do not want data duplicated across documents. For read heavy systems, duplication is fine because we are optimizing to read data easily without complex joins.
