# Schema Validation

- Define some structure and rules for a  collection and ensure incoming documents are validated.
- Each collection should have these mandatory fields and accept only these type of values.
- All insert and update commands will first validate the data.


## Validation Level

- All inserts are validated.
- For updates, it's possible that we defined validation rules later and hence there is already data in a collection that is invalid.
- Validation level set to strict means that all updates will be validated.
- Moderate value means For update operation only validate the document if it is already valid.
