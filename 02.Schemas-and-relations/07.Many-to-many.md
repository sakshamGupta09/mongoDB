# Many to many relation

## Embedding IDs

- Students ↔ Courses
- If each student takes only a small, bounded number of courses
- The list is relatively small.
- You mainly query from one direction.
- The relationship itself has no additional information.

```javascript
{
  "_id": 1,
  "name": "John",
  "course_ids": [101, 102, 103]
}

{
  "_id": 101,
  "name": "Math"
}
```

## Separate relationship collection

Student ←── Enrollment ──→ Course

- Both sides can have many relationships.
- The relationship can grow significantly.
- You query from both directions.
- The relationship has its own data.

```javascript
{
  "student_id": 1,
  "course_id": 101,
  "enrolled_at": "2026-09-01",
  "grade": "A"
}
```
Here, enrollment isn't merely a relationship—it has its own attributes.
