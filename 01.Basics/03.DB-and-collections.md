# Create DB and collections

```javascript
show dbs
```
- Gives a list of all the DBs on this server.


```javascript
use DBName
```
- Out of all the DBs, I want to switch to this DB. `db` variable will than point to the instance of that selected database.
- If that DB does not exists, it will create that DB automatically on the fly. No prior setup required.


```javascript
db.collection.CRUD
```
- On the db variable, we can access collections.
- We can even point to collections that doesn't exists yet.
- Once we reach collections, we can run CRUD methods.


## Documents

- Documents are always a JSON.
- When we insert document into collection, we insert a JSON.
- When we read from collections, we get back documents which are JSON.
