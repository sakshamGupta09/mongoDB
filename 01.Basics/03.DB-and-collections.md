# Create DB and collections

```javascript
show dbs
```
- Gives a list of all the DBs on this server.


```javascript
use DBName
```
- Out of all the DBs on this server, I want to work to this DB.
- `db` variable will than point to the instance of that selected database.
- If that DB does not exists, it will create that DB automatically on the fly. No prior setup required.


```javascript
db.collectionName.CRUD
```
- On the db variable, we can access collections defined on that DB.
- We can even point to collections that doesn't exists yet.
- Once we reach a collection, we can run CRUD methods on collection instance.
